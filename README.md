# movie_watchlist_app

# WatchLitz # 
is a modern movie watchlist application designed to provide a clean, intuitive, and efficient way for users to manage their movie interests. The app allows users to browse movies, view essential details such as title, year, genre, and duration, and maintain a personalized watchlist.
Built using Flutter, the application ensures smooth cross-platform performance. Movie data is fetched through external APIs like TMDb, enabling real-time and up-to-date content.
